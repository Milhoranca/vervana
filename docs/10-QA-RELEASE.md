## Gate criativo

- [ ] Ponto de vista identificável.
- [ ] Primeiro frame comunica oferta/promise.
- [ ] Trabalho original, não colagem de tendências.
- [ ] Cada seção possui função.
- [ ] Copy e provas são verdadeiras.
- [ ] Mecanismo cinematográfico reforça a narrativa.

## Gate visual

- [ ] Hierarquia tipográfica clara.
- [ ] Quebras importantes aprovadas.
- [ ] Contraste e foco intencionais.
- [ ] Espaço vazio deliberado.
- [ ] Crops preservam foco e legibilidade.
- [ ] Não há repetição de template seção após seção.

## Gate funcional

- [ ] Navegação e CTAs.
- [ ] Links externos/internos.
- [ ] Formulários, erros e sucesso.
- [ ] Menu e overlays.
- [ ] Anchor, back/forward e refresh.
- [ ] Repeated mount/unmount e resize.

## Gate motion

- [ ] Um mecanismo domina.
- [ ] Feedback de input é imediato.
- [ ] Nada essencial depende da animação.
- [ ] Touch possui alternativa.
- [ ] Reduced motion preserva significado.
- [ ] Cleanup verificado.

## Gate técnico

- [ ] Build.
- [ ] Lint/typecheck.
- [ ] Testes existentes.
- [ ] Console limpo.
- [ ] Sem 404 de assets.
- [ ] Sem hydration/layout warnings.
- [ ] Metas de performance avaliadas.
- [ ] Metadata/SEO/social cards.

## Formato de issue

```text
[P0–P3] Título curto
Evidência: o que foi observado e onde.
Impacto: clareza, conversão, acessibilidade, performance ou manutenção.
Correção: mudança pretendida.
Aceite: condição observável que prova a correção.
```
